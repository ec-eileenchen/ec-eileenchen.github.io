Data Preprocessing

The data preprocessing stage consists of four main purposes. Feature engineering, creating interaction features that captures deviations from categorical group means and standard deviations, follows by label encoding for categorical features and standardization for numerical features. Lastely, median simple imputation with missing-value indicator flags is implemented to preserve the informativity of the original patterns.

Model Training with Time Series Validation

The model building section includes implementation of a time-series cross-validation strategy to prevent data leakage. It performs hyperparameter tuning over a defined parameter space for a LightGBM model, the performance is evaluated witht he AUC metric. With each fold, the SMOTE oversampling technique is applied to the training data to address class imbalance. The best hyperparameters are selected based on the highest mean cross-validation AUC.

Explainable AI

The explainable AI section examines the model's interpretability using SHAP to explainthe predictions of the trained LightGBM model. The analysis generates two summary visualization plots, a bar chart ranking the top 10 features by mean absolute SHAP value and a violin plot revealing the distribution and magnitude of each of the top 10 feature's effects across all samples.
